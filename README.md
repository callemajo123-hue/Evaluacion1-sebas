# Hackatón ADSO 2026

Página web oficial de la Hackatón ADSO 2026: 24 horas para construir una solución web que ayude a un negocio de la región.

## Descripción

Sitio informativo del evento organizado por el SENA CDITI Dosquebradas para el programa ADSO. El evento se realiza el sábado 5 de diciembre en el CDITI Dosquebradas.

## Secciones del sitio

- *Inicio:* presentación del evento.
- *Agenda:* actividades del día con su hora.
- *Inscripción:* cupo, requisitos y contacto.
- *Ubicación:* dirección y enlace al mapa.

## Tecnologías

- HTML5
- CSS3
- Git y GitHub

## Cómo clonar el repositorio

bash
git clone https://github.com/callemajo123-hue/evaluacion1-git-github.git
cd evaluacion1-git-github


Luego abre index.html en el navegador o con Live Server en VS Code.
